# InsightForge — AI-Powered BI Assistant

## Overview
InsightForge is a Python-based business intelligence application
that allows users to upload CSV datasets, inspect data quality,
explore descriptive statistics, create visualizations, and ask
basic questions about their data.

## Features
- CSV dataset upload and preview
- Missing-value and duplicate-row analysis
- Descriptive statistics
- Histograms and correlation matrices
- Category-level comparisons
- Basic question-based data analysis
- CSV export

## Tech Stack
Python, Streamlit, Pandas, Matplotlib

## Run Locally
1. Install Python 3.10 or later.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Start the app:
   `streamlit run app.py`

## Project Status
Starter implementation. LangChain, retrieval-augmented generation
(RAG), and external LLM integration are not yet implemented.
